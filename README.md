# To-mobile

Repositorio base para una futura aplicación móvil.

## Objetivo
Definir la idea y la plataforma antes de seleccionar el framework y construir la aplicación.

## Estructura propuesta
```text
.
├── src/          # Código de la aplicación
├── assets/       # Imágenes, iconos y recursos
├── docs/         # Requisitos y decisiones técnicas
├── tests/        # Pruebas
├── .gitignore
└── README.md
```

## Decisiones pendientes
- Plataforma: Android, iOS o ambas.
- Lenguaje y framework.
- Versión mínima del sistema operativo.
- Almacenamiento local o remoto.
- Servicios externos necesarios.

## Calidad
- Mantener componentes pequeños y reutilizables.
- No incluir claves API ni contraseñas en el repositorio.
- Probar en distintos tamaños de pantalla.
- Documentar instalación y ejecución.

## Estado
🟡 Plantilla inicial. Framework y funcionalidades por definir.
